# Band Jump — IELTS Writing 4.5 → 6.0

> 백지 작문 없이, 모델 문장·드릴·재조립으로 IELTS 라이팅 4.5를 6.0으로 올리는 8주 러닝 앱

**지금 바로 써보기:** https://sidebatch.github.io/ielts-writing-45-to-60/

모바일에서 홈 화면에 추가하면 앱처럼 쓸 수 있어요 (PWA 지원).

---

## 왜 "쓰지 않는" 라이팅 앱인가

Band 4.5 학습자에게 백지에 에세이를 쓰게 하는 건 가장 비효율적인 훈련입니다.
좋은 문장이 머릿속에 없는데 출력부터 시키면, 나쁜 문장만 반복 연습하게 되니까요.

Band Jump는 순서를 뒤집습니다.

1. **모델 먼저** — 도달 가능한 Band 6.5 수준의 문장·문단·에세이를 먼저 보고 읽습니다 (Band 9가 아닙니다. 6.0의 목표는 "오류가 거의 없고 구조가 완전한 글"입니다)
2. **패턴 발견** — 예문을 여러 개 보며 공통 모양을 먼저 느끼고, 문법 용어는 마지막에 이름표처럼 붙입니다
3. **드릴과 재조립** — 고르기, 순서 맞히기, 조각 조립으로 패턴을 몸에 붙입니다
4. **간격 반복** — 틀린 문제는 1일 → 3일 → 7일 간격으로 다시 만나, "아는 것"이 아니라 "몸이 기억하는 것"으로 만듭니다

## 8주 커리큘럼 (하루 1레슨, 약 15분)

| 주차 | 주제 |
|---|---|
| 1주 | 문장 기초 — 주어+동사, 문장 경계, 주어-동사 일치, 시제 |
| 2주 | 이유·결과 확장 — because / so / because of / to |
| 3주 | 복문 — although / if / when / which·who |
| 4주 | 문단 — 주제문, 근거·예시, 연결어, 문단 조립 |
| 5주 | 서론 — 패러프레이즈, 유형별 입장문 |
| 6주 | 본문 심화 — 설명 확장, 토픽 청크 (교육·기술·건강·환경·일·사회·가족·범죄) |
| 7주 | 유형별 구조 — 의견형 / 논의형 / 장단점형 / 문제해결형 / 이중질문형 |
| 8주 | 결론과 에세이 전체 조립, 약점 복습, 최종 점검 |

## 구성

- **시작 진단** — 12문제로 공식 평가기준 4개(TR·CC·LR·GRA) 중 어디서 점수가 새는지 확인
- **레슨 40개** — 모델 문장 → 패턴 → 드릴 → 재조립
- **자유 훈련장** — 문장 수술실 24 · 문장 키우기 53 · 문단 조립 6 · 패러프레이즈 15 · 토픽 청크 32
- **에세이 조립** — Band 6.5 모범 에세이 6편(각 250단어 이상 — 실제 시험 최소 분량 충족)을 문장 단위로 조립하며 전체 구조 학습
- **간격 반복 복습** — 틀린 문제가 자동으로 돌아오는 복습 큐
- **이번 주 진도** — 홈에서 월요일부터 오늘까지 완료한 레슨·학습한 날·끝낸 복습 문제 수를 한눈에 확인 (주 5레슨 페이스 안내 포함)

콘텐츠는 IELTS 공식 밴드 디스크립터(4.5와 6.0의 차이: 의미가 막히는 오류의 유무, 복문의 안정성, 문단 구성)에 맞춰 설계했고, 시험에서 피해야 할 비격식 클리셰는 가르치지 않습니다.

## 기술

- 단일 `index.html` (프레임워크 없음), GitHub Pages 배포, PWA (네트워크 우선 캐시)
- 진도는 브라우저 `localStorage`에만 저장 — 서버 전송 없음
- 접근성: 모든 터치 영역 최소 44px, 키보드 조작(모델 문장·레슨 행 Enter/Space)과 포커스 표시, 텍스트 명도 대비 WCAG AA, 동작 줄이기(prefers-reduced-motion) 존중
- 오프라인: 한 번 연 화면은 서비스워커 캐시로 오프라인에서도 열립니다 (오류 응답은 캐시하지 않고, 화면 이동은 앱 셸로 폴백)
- 공유·검색: Open Graph/Twitter 카드 메타(전용 1200×630 이미지 `og-image.png`)와 canonical·구조화 데이터(JSON-LD)를 갖추고, 설명 문구는 페이지·매니페스트·소셜 메타가 하나의 문장으로 통일돼 있습니다
- 현재 버전: **v1.14.0**
